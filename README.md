# ChatJump

**ChatJump** is a Chrome extension that makes navigating long AI conversations effortless.  
It automatically creates a clickable index of all your prompts in **ChatGPT**, **Claude**, and **Gemini**, letting you jump to any question instantly — no more endless scrolling.

---

## ✨ Features

- 📜 **Automatic Prompt Index** — Lists all your questions in a neat sidebar
- ⚡ **One-Click Navigation** — Jump straight to the exact answer
- 🤖 **Multi-Model Support** — Works with ChatGPT, Claude, and Gemini
- 🎯 **Minimal & Lightweight** — No extra clutter, just speed

📌 Usage
Open any conversation — ChatJump’s sidebar should appear automatically
